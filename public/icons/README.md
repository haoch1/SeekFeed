# SeekFeed icons

`seekfeed.svg` is the original S monogram for SeekFeed. The 192px and 512px PNG files use the same mark for PWA and Apple touch icons.

`ui.svg` contains selected Lucide Static 1.59.0 icons, shared by server-rendered components and client-rendered rows and notifications. It requires no icon JavaScript runtime. License: `licenses/lucide.txt`.
