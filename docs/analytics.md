# 统计分析

## 数据与时间

统计基于已收录的 RSS 帖子，按发帖时间分组，不等同于 NodeSeek 全站流量或完整历史。采集延迟、历史覆盖和数据保留范围会影响结果。

总览支持今日、近七天、近三十天及全部记录。API 通过 `offset` 指定时区偏移分钟，界面使用浏览器时区。日期边界和时段归属使用同一偏移。最新帖子顶部的累计收录数不受统计页所选日期范围限制。

## 总览

| 指标／视图 | 定义与行为 |
| --- | --- |
| 收录帖子 | 所选日期与分类范围内的帖子数量 |
| 活跃作者 | 范围内发帖作者去重数量；人均发帖为帖子数除以作者数 |
| 活跃分类 | 范围内具有帖子的分类数量 |
| 高峰时刻／日均发帖 | 今日显示发帖最多的小时；较长范围显示日均数量 |
| 发帖趋势 | 按时段分组，支持柱形与折线切换 |
| 分类占比 | 分类名称、帖子数、占比与环图联动；点击分类应用总览过滤 |
| 作者贡献 | 按作者发帖数量区间分组，展示作者数及帖子贡献 |
| 活跃作者 | 按帖子数排序，支持 TOP 5／10／20／50，默认 TOP 5 |
| 发帖时段 | 按星期与小时聚合热力分布，颜色表示帖子数量 |
| 热门标题词 | 最近最多 5,000 篇标题分词，忽略常用停用词和纯数字；每篇每词计一次，展示最多十二项 |

活跃作者及关键词作者榜使用采集页面提供的数字用户 ID 生成 NodeSeek 主页链接。作者榜沿用姓名分组；同一名称关联多个已确认 ID 时不提供主页链接。帖子列表仅在帖子编号与作者名称均与采集记录一致时提供链接。未确认身份的记录保留普通文本，不按用户名推测地址。链接统一在新标签页打开，支持键盘与触屏操作，桌面悬停显示“查看用户主页”。身份信息随既有热榜采集保存，不增加源站请求或改变订阅匹配规则。

总览的日期和分类作用于所有关联视图。访客仅获得公开帖子及聚合统计；订阅、命中和通知数据需要认证。

## 关键词分析

关键词分析独立选择日期和匹配范围，不继承总览分类。支持一个主关键词与最多两个对比关键词。文本经过兼容规范化与大小写归一化后执行包含匹配，不使用订阅正则语法。

帖子搜索中的容错匹配选项不作用于统计分析。关键词分析按输入文本统计，避免将近似拼写合并计数。

- 每个关键词分别统计全天数量、活跃作者、分类、1／3／6 小时分布与近七天趋势。
- 同一帖子对同一词仅计一次，多个词的共同命中单独展示，不将各词相加作为去重总量。
- 发帖占比使用“关键词帖子数 ÷ 同期已收录总帖数”。日期、时区和截止时刻保持一致；匹配范围仅影响关键词计数，不缩小总帖数。每个关键词分别以 0–100% 比例条展示日期占比，并列出分子、分母和百分比。对比关键词可能命中同一帖子，各词占比不相加，不使用互斥分类的饼图或堆叠占比图。
- 时段分布与近七天趋势分别支持“帖子数／发帖占比”指标切换，默认帖子数，保留现有柱形／折线切换。时段占比使用该分组的总帖数，3／6 小时分组先合计分子、分母后计算比例；日趋势使用每一天各自的总帖数。百分比坐标轴根据当前对比序列共同缩放；日期比例条始终以 100% 为满格。
- 总帖数大于零且无关键词命中时，占比为 0%；总帖数为零或缺少分母时显示“—”，占比曲线保留间断，不补成 0%。低于 0.1% 的正占比显示“＜0.1%”。提示框同时展示同期总帖数、各词帖数及占比，普通、放大和移动端视图使用同一计算口径。指标与样式切换不新增查询，日期、粒度、刷新及对比词移除保留各图选择。
- 总览发帖趋势、关键词时段分布及近七天趋势均支持柱形与折线切换。关键词图表使用多序列共同坐标轴；柱形并排展示，折线通过颜色、线型、点形和图例区分关键词。切换不更改统计条件或发起额外分析请求，普通与放大视图共用当前样式；时段粒度、日期切换和后台刷新保留样式选择。
- 分类及作者明细展示当前选中的关键词，并明确标注名称。
- 当前日期统计至查询时刻，时段图仅展示已开始的分组；正在进行的分组保留，尚未开始的分组不占用图表空间。已过去且数量为零的时段保留，历史日期展示全天。该规则同时适用于普通视图和放大视图；历史不足及上一日记录不完整时显示提示。
- 推荐词与热门标题词仅填入主关键词，保留已选日期和对比词，等待“开始分析”或回车提交。
- 对比词可逐项移除；模块支持重置、收起与展开。点击趋势日期可加载对应日期的数据。

## 图表交互

鼠标在柱体、实际数据点或其紧邻区域才触发提示；坐标标签、空白、图例及滚动条不应触发。移出图形、滚动、切换视图或失去焦点时清除临时提示。点击可固定选中项，Escape 取消，方向键切换数据项。

发帖趋势、发帖时段、关键词时段分布及近七天趋势提供放大按钮。放大视图在独立弹窗中按可用宽度展示完整时段，保留图表切换、对比序列、数据点检查及日期选择。放大与缩小按钮使用同尺寸的对角箭头，分别朝外与朝内。缩小按钮、Escape 或点击遮罩可退出，原面板的控件状态与滚动位置保留。密集图表减少常驻数值标签，具体数值通过点选或悬停查看。

移动端支持点选，长图在面板内部横向滚动，不扩大整个页面。排行榜在内部滚动，保持同排面板高度一致。图形颜色使用统一主题变量，并以文字、数值或线型补充信息。

## 导出与范围限制

CSV 由浏览器根据当前总览数据生成，包含筛选范围、统计起止时间、时区、总览指标、各时段数量、分类、最多五十名作者和热门标题词。

关键词分析不是实时舆情全量检索；RSS 未收录、摘要缺失或超出保留范围的内容不会纳入。公开样本不足时不补造历史记录，也不将未观测数据解释为真实零值。热榜数据来源及评分规则另见 [热榜](hot-ranking.md)。
