# SeekFeed 优化记录

本文记录功能调研、主要设计决策与可靠性改进。对照范围为公开项目说明与本仓库实现，不构成第三方性能测试。参考链接统一列于 [README](../README.md#参考项目与资源)。

## 功能与架构对照

| 对照项目 | 调研范围 | SeekFeed 决策 |
| --- | --- | --- |
| nodeseek-keywords | 暂停、发送上限、重试与 RSS 异常处理 | 规则独立开关、持久化待发送状态、每轮上限和异常退避 |
| nodeseek-rss-telegram-bot | 组合关键词、排除规则及多用户目标 | 组合与排除过滤；维持单管理员架构 |
| NodeSeekRSSMonitor | 分类监控、Workers／D1、备用来源与摘要 | 保留 Bun／SQLite 单应用部署；备用源和摘要不列为现有功能 |
| ReUI | 导航、表单、卡片、按钮、开关与分页 | 使用统一设计变量，以服务端 JSX 和原生脚本实现 |
| Discourse、Plausible、Umami | 社区报告、筛选联动及紧凑指标 | 分离总览与关键词分析，提供分类、作者、趋势与时间分布 |

## 监控与投递

| 执行环节 | 当前机制 |
| --- | --- |
| 并发控制 | 手动与定时 RSS 任务共享执行中的 Promise，单实例不重叠 |
| 调度 | 每轮结束后安排下一轮；状态读取实际运行实例 |
| 失败重试 | 待发送状态持久化，成功后才记录已推送；失败批次轮转 |
| 发送上限 | 每轮限制通知数量，超出部分保留于队列 |
| RSS 异常 | 验证响应内容，拒绝将验证页视为空 RSS；仍尝试处理已有队列 |
| 来源退避 | 连续错误按倍数延长间隔，恢复后返回配置频率 |
| 数据写入 | 批量事务及帖子 ID 去重，失败回滚 |
| 规则匹配 | 普通关键词忽略大小写，正则保留标记语义，作者精确匹配 |
| 统计一致性 | 更新时失效相关缓存，成功通知仅统计实际投递状态 |
| 存储连接 | 应用复用 SQLite 连接，设置缓存上限与锁等待时间 |

## 热榜

独立采集公开列表的浏览与回复计数，以近期增量和时间衰减计算实时热度。日榜和周榜按明确的发帖时间范围计算累计互动。采集具有持久化冷却、随机间隔、失败退避及旧榜保留机制。

该实现不依赖第三方热榜接口，不保证覆盖论坛全部帖子，也不承诺固定的榜单更替率或限流豁免。采样、回放结果与公式见 [热榜规则](hot-ranking.md)。

## 权限与账号

公开接口只返回论坛公开字段及允许公开的聚合值。订阅、命中、通知状态、配置和设备管理在服务端要求有效 Session。认证与 API 不使用共享缓存，Service Worker 仅缓存静态资源。

账号展示缓存与会话绑定；设备管理标识不能作为登录凭据。支持单设备退出、全部退出与独立头像更新。密码采用哈希保存，不能通过接口还原。

## 界面与分析

工作台统一导航、表单、图标、反馈与主题。手机布局使用紧凑工具栏、可收起侧栏和卡片内部滚动。刷新保留已加载列表及阅读位置，页面切换避免文字位移残影。

统计包含趋势、分类、作者贡献、活跃时段、标题词和 CSV。关键词最多三个词独立对比，共用时间坐标，并提供交集及所选词明细。推荐词只填入输入框，由用户提交分析。交互及指标定义见 [界面规范](style-guide.md) 和 [统计分析](analytics.md)。

## 验证与已知限制

仓库使用 Bun 自动化测试、生产构建和 Python 采集器测试；CI 定义见 [CI/CD](CI-CD.md)。界面验证应覆盖桌面、窄屏、明暗主题、键盘、触控、错误及加载状态。测试数量随版本变化，以对应提交的 CI 结果为准。

当前单篇帖子记录第一个匹配订阅，不提供完整的多对多历史。暂停期间未命中的历史内容不自动补发。通知发送成功至本地状态写入之间发生进程中断时，可能重复投递，未提供恰好一次投递保证。

多用户隔离、备用 RSS、AI 摘要、多通道通知和持久化逐条投递日志属于潜在扩展方向，不属于现有功能。
